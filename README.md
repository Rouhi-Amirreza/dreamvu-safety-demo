# DreamVu Safety Studio

Interactive recorded demonstrations of human-safety capabilities: people detection and tracking, counting, pose and posture, helmets, zones, movement cues, falls, and observation freshness.

Open the [public demo](https://rouhi-amirreza.github.io/dreamvu-safety-demo/).

Eleven scenes have independent feature switches. All fourteen layers are available on 360° clips; the twelve applicable layers are available on 2D clips. Defaults suit each scene.

These are offline prototype results, not a live inference service. Apparent proximity is a body-size estimate, not calibrated distance. Results can include missed detections, uncertain classifications, and identity changes.

This repository contains only the static player and published demo assets. Model weights and the development workspace are excluded. Video credits and licenses are retained in the gallery and player; source media remains under its stated license.

GitHub Pages publishes the root of the main branch. All asset paths are relative so the player works under the project URL.
